# 云算力目录

这个目录是「云端服务器工具」的工作目录，默认就是程序目录下的 `云算力/`，
不需要任何固定绝对路径。

把你自己服务器相关的脚本放在这里，例如：

- `ssh_exec.ps1`  —— 执行远端命令
- `autodl_power.py` —— AutoDL 开关机
- 连接信息（主机、端口、账号、密码）请写在 `rem_config.json` 的 `cloud` 段，
  或在本目录放自己的凭据文件，注意不要提交到公开仓库。

程序会自动读取本目录；如果放在别处，可以用环境变量指定：

```powershell
setx REM_CLOUD_DIR D:\你的云算力目录
```
