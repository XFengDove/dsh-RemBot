# dsh-RemBot

> **基于 QQ 的远程控制程序** —— 允许通过 QQ 控制电脑算力资源、执行任务、爬取互联网资源等 Agent 功能。

---

## 为什么使用

并不是每个人都愿意随身带一台笔记本。智能手机上虽然有类似功能的软件，但用起来并不"随心所欲"——我们无法自由地扩展它们的功能，局限性很大。

dsh-RemBot 把自己的电脑（笔记本、台式机均可，几乎不限操作系统，只要 QQ 能工作）直接投放到互联网上，通过一种极简单但是安全的方式远程控制设备，大幅降低了操作门槛。

## 已实现的功能

### 日常闲聊

不配置任何扩展时几乎只有这个功能，无门槛：文件发送与同步（模拟网盘）、智能化网页搜索服务。

> 我曾设计过每 15 分钟自动检查是否主动发起会话，大概每天会有 5 至 10 次主动会话，蛮有意思的。后来程序改着改着这个功能莫名其妙消失了，目前已经被我剔除，不确定有没有删干净。

### 文件与创作

| 功能 | 说明 |
|---|---|
| 本地文件发送与接收 | 具体限制约等于没有 |
| 文生图 / 文生视频 / 图生视频 | 调用本地基础脚本，也允许自定义高级工作流，实现更快速、更高级的调用；允许智能体自行编辑新工作流、修正工作流错误 |
| 提示词扩写 | 仅需自然语言就能生成一张优秀的产品图（能到什么程度取决于模型性能） |
| Blender 建模 | 需要搭配相应的 MCP |
| 多模态伪装 | deepseek 等模型通过本地其他模型伪装多模态，类似豆包的二次封装 |
| MiniMax H3 Cosplay 生图 | 用视频模型产出 5 帧画面、取其中间帧，效果不错，适合场景渲染 |

### 自动化与云

| 功能 | 说明 |
|---|---|
| 自动配置云服务器 | 常用算力服务器外挂 ComfyUI 模块；ComfyUI 在本地已跑通，建议使用 SSH + 密码，默认脚本也是按 SSH 写的 |

### 其他意外收获

- **安全性**：没有开发主动或被动的加好友、加群接口（所有加好友、加群都需要人工操作）；通信软件本身提供隐私加密。强烈建议开一个 QQ 会员，封号概率小一点。
- **多人同时协作**：如果机器人所在的账号有群聊，群里所有人都可以使用全部功能（非 @ 只聊天，但不做限制，会回复每个人的消息；设有强制冷却时间和怠惰机制）。如果是一个非常活跃的群聊，Token 和上下文都是不小的考验。强制压缩会话长度默认为 100 轮 × 95%，约 `(100 × 2) × 0.95` 条消息，可以自行调整。我还没用出来过——因为调用工具的消息不会累计进上下文，只有当前轮次的工具调用消息会被计入。
- **多 AI 同时在线**：得益于群聊机制，允许多个运行本程序的 QQ 账号在同一个群里工作、聊天，同时管理多台电脑。每个 AI 自动判断要不要回复（和上面"每 15 分钟主动发起会话"类似，似乎也被我删了），每个 AI 一次最多三句话。
- **Cosplay 网盘**：因为有文件发送与接收功能，可以脱离网盘服务商，把自己的电脑当成远程网盘，而且不用手动一个个找文件。
- **类 Copilot 服务**：智能化网页搜索。

## 基础指令

> `*` 为必填项。

| 指令 | 参数 | 说明 | 可用模式 |
|---|---|---|---|
| `mod` | `-online` / `-local` | 切换大语言模型使用 API 服务还是本地服务。本地模型建议使用 **Gemma-4 27B**，原生多模态 | 双模式 |
| `画图` | `-height/-h <value>`、`-weight/-w <value>`、`-prompt* <value>`、`-model <model_name>` | 调用生图模型。不走本地模型记忆，但会调用本地模型补全和优化提示词 | 本地模式 |
| `视频` | `-height/-h <value>`、`-weight/-w <value>`、`-prompt* <value>`、`-model <model_name>`、`-time <value>` | 调用视频模型（调用生图模型）。不走本地模型记忆，但会调用本地模型补全和优化提示词 | 本地模式 |
| `dellast` | `<value>` | 双模式均可用，不加 `<value>` 默认删除最后一条记忆，数值为 int。本地模式会自动重载模型；Ollama 会自动缓存上下文，目前我还没找到合适的办法，这个问题似乎也没有根治 | 双模式 |

> 其他指令待补全。
