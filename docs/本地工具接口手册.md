# Rem 本地工具接口手册

> 适用：A 实例 `http://127.0.0.1:5700`，B 实例 `http://127.0.0.1:5701`
> 版本：2026-10-20
> 入口：`POST /tool_event`（兼容 `/api/tool_event`）

## 1. 用途

本地工具（ComfyUI 脚本、下载器、训练任务、定时任务等）把一条**任务概况**推给 Rem：

- 正文只接受文本；
- 任务名字、任务目的、任务结果必填；
- 可附带图片/视频附件；
- 把概况私聊中继给管理员，并把图片/视频作为附件发给管理员；
- 附件保存到 `qq-bot-output/tool_inbox/<事件ID>/`，同时写 `event.json`。

## 2. 鉴权

请求头二选一：

```http
Authorization: Bearer <local_api.token>
```

```http
X-API-Token: <local_api.token>
```

> 当前实现读取 `Authorization: Bearer ...`。Token 在 `rem_config.json` 的 `local_api.token`。
> A/B 各自独立生成；不要把端口暴露到公网。

## 3. 文本正文（application/json）

只允许文本字段，不允许把二进制塞进 JSON。

```http
POST /tool_event HTTP/1.1
Host: 127.0.0.1:5700
Authorization: Bearer <token>
Content-Type: application/json; charset=utf-8

{
  "task": "训练数据整理",
  "purpose": "把本批图片按角色分类，供后续训练",
  "result": "共整理 128 张，已按角色分到 6 个目录",
  "source": "anima-pipeline",
  "meta": "{\"batch\": 12}"
}
```

### 字段

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `task` | ✅ | string | 任务名字，≤200 字 |
| `purpose` | ✅ | string | 任务目的，≤1000 字 |
| `result` | ✅ | string | 任务结果，≤3000 字 |
| `source` | ❌ | string | 来源工具名，默认 `local_tool` |
| `meta` | ❌ | string | 附加文本（JSON 字符串），预留 |

别名：`task_name` 可作为 `task` 的别名。

## 4. 带附件（multipart/form-data）

正文仍然是文本：把 JSON 放在 `payload` 文本字段，附件用文件字段。

```http
POST /tool_event HTTP/1.1
Host: 127.0.0.1:5700
Authorization: Bearer <token>
Content-Type: multipart/form-data; boundary=----RemBoundary

------RemBoundary
Content-Disposition: form-data; name="payload"
Content-Type: text/plain; charset=utf-8

{"task":"渲染完成","purpose":"生成本批角色图","result":"成功 3 张，失败 0 张","source":"comfyui"}
------RemBoundary
Content-Disposition: form-data; name="file"; filename="preview.png"
Content-Type: image/png

<二进制 PNG>
------RemBoundary--
```

### 附件规则

| 项目 | 限制 |
|---|---|
| 类型 | 仅 `image/*`、`video/*` |
| 数量 | ≤ `local_api.max_attachments`（默认 9） |
| 总大小 | ≤ `local_api.max_body_mb`（默认 200 MB） |
| 保存 | `qq-bot-output/tool_inbox/<事件ID>/` |
| 中继 | 图片按图片发，视频按视频发；同时发文本概况 |

## 5. 响应

成功：

```json
{
  "ok": true,
  "id": "20261020_165018_b55f42",
  "attachments": [
    {
      "name": "preview.png",
      "type": "image/png",
      "size": 200092,
      "path": "C:\\...\\qq-bot-output\\tool_inbox\\20261020_165018_b55f42\\preview.png"
    }
  ],
  "notified": true,
  "admin": 3043978689
}
```

| 状态码 | 含义 |
|---|---|
| 200 | 接收并已尝试中继 |
| 400 | 缺字段 / JSON 错误 / 附件过多 |
| 401 | Token 缺失或错误 |
| 413 | 正文或附件过大 |
| 415 | 附件不是图片/视频 |
| 429 | 超过每分钟次数（默认 30） |
| 500 | 内部错误 |

## 6. 调用示例

### PowerShell（纯文本）

```powershell
$token = (Get-Content .\rem_config.json -Raw | ConvertFrom-Json).local_api.token
$body = @{
  task    = "接口自检"
  purpose = "验证本地工具能否中继"
  result  = "文本事件测试通过"
  source  = "manual-test"
} | ConvertTo-Json -Compress

Invoke-RestMethod 'http://127.0.0.1:5700/tool_event' `
  -Method Post `
  -Headers @{ Authorization = "Bearer $token" } `
  -ContentType 'application/json; charset=utf-8' `
  -Body ([Text.Encoding]::UTF8.GetBytes($body))
```

### Python（带图片附件）

```python
import json, requests

token = json.load(open("rem_config.json", encoding="utf-8-sig"))["local_api"]["token"]
payload = {
    "task": "渲染完成",
    "purpose": "生成本批角色图",
    "result": "成功 3 张，失败 0 张",
    "source": "comfyui",
}
with open("preview.png", "rb") as f:
    r = requests.post(
        "http://127.0.0.1:5700/tool_event",
        headers={"Authorization": f"Bearer {token}"},
        data={"payload": json.dumps(payload, ensure_ascii=False)},
        files={"file": ("preview.png", f, "image/png")},
        timeout=30,
    )
print(r.status_code, r.json())
```

### curl

```bash
curl -X POST http://127.0.0.1:5700/tool_event \
  -H "Authorization: Bearer $REM_TOKEN" \
  -H "Content-Type: application/json; charset=utf-8" \
  -d '{"task":"任务名","purpose":"目的","result":"结果","source":"tool"}'
```

## 7. 中继行为

Rem 收到后：

1. 校验 Token、字段、附件类型和大小；
2. 保存附件与 `event.json`；
3. 把任务/目的/结果直接整理成概况，私聊发给管理员；
4. 依次发送图片/视频附件；
5. 返回 JSON。

管理员收到：

```text
【本地工具事件】20261020_...
任务：渲染完成
目的：生成本批角色图
结果：成功 3 张，失败 0 张
来源：comfyui
附件：1 个
- preview.png（image/png，0.19 MB）
```

## 8. 配置

```json
"local_api": {
  "enable": true,
  "token": "<随机 48 位十六进制>",
  "max_body_mb": 200,
  "max_attachments": 9,
  "max_per_minute": 30
}
```

- Token 泄露时直接改 `local_api.token` 并重启 Rem；
- A/B Token 不同；调用 B 用 `5701`；
- 只监听 `127.0.0.1`，不要做端口映射。
