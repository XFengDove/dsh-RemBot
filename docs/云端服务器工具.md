# 云端服务器工具手册

> 适用：A（5700）与 B（5701）
> 依赖程序目录下的 `云算力/` 目录（可用环境变量 `REM_CLOUD_DIR` 改到别处）
> 权限：**仅管理员 QQ 可调用**

## 1. 工具

| 工具 | 作用 |
|---|---|
| `cloud_status()` | 查看 GPU / 磁盘 / 内存 / 负载 / 进程 |
| `cloud_exec(命令)` | 在服务器执行 bash 命令 |
| `cloud_read(路径)` | 读取远端文本文件 |
| `cloud_download(路径, 文件名?)` | 下载到本地 `qq-bot-output/cloud/`，再用 `send_file` 发出 |
| `cloud_power(status\|start\|stop, 实例?)` | AutoDL 实例状态 / 开机 / 关机 |

## 2. 登录方式

复用现有：

```text
云算力\ssh_exec.ps1
```

它从 `云算力平台账户密码.txt` 解析 `ssh -p 端口 用户@主机` 和密码，
通过 `askpass_env.exe` 完成密码登录；不需要把密码写进 Rem 配置。

## 3. 开关机

复用：

```text
云算力\autodl_power.py
```

Playwright + 本机 Edge + 已登录的 `autodl_browser_profile`：

```text
cloud_power("status")                 # 看实例状态
cloud_power("start", "实例ID")        # 开机
cloud_power("stop", "实例ID")         # 关机
```

当前默认实例：

```text
a03b4fb96c-3e1536d5   （北京B区 581机 RTX 5090）
```

`start/stop` 会产生费用，只有管理员明确要求时才能调用。

## 4. 配置

```json
"cloud": {
  "enable": true,
  "root": "云算力",
  "ssh_exec": "ssh_exec.ps1",
  "power_script": "autodl_power.py",
  "instance": "a03b4fb96c-3e1536d5",
  "timeout_seconds": 120,
  "max_output_chars": 8000,
  "max_download_mb": 50
}
```

- 服务器关机时 `cloud_status` 返回 SSH 255，先 `cloud_power start`；
- 开机后 SSH 端口才开放；
- `cloud_exec` 会拦截 `rm -rf /`、`mkfs`、`shutdown`、`reboot`、`dd`、`kill -9 1` 等高风险命令；
- `cloud_read/download` 只允许 `/root`、`/home`、`/workspace`、`/tmp`、`/data`、`/mnt`；
- 下载上限默认 50 MB，超过请用服务器侧压缩/分片。

## 5. 开机后的算力守护

`cloud_power("start")` 成功后会自动拉起：

```text
server_guard.py
```

流程：

```text
开机 → 等 5 分钟
  → 问雷姆：服务器在运行吗？有人在用算力服务器吗？没有的话关掉服务器。
  → 再等 5 分钟；服务器还开着就再问一轮
  → 服务器关闭（SSH 端口关闭）后退出
```

- 日志：`server_guard.log`
- 间隔/首轮等待在 `cloud.guard` 配置；
- 只问，不直接关机；由雷姆判断 `cloud_status`（GPU 占用、`who`、进程）后决定是否 `cloud_power stop`。

## 6. 示例

```text
你：看下服务器现在什么状态
雷姆：cloud_status()

你：把 /root/autodl-tmp/train.log 最后 100 行发我
雷姆：cloud_exec("tail -100 /root/autodl-tmp/train.log")

你：把 /root/autodl-tmp/result.zip 下载发我
雷姆：cloud_download(...) → send_file(...)

你：把 5090 实例开机
雷姆：cloud_power("start", "a03b4fb96c-3e1536d5")
```

## 6. 环境

- `ssh.exe`（Windows 自带 OpenSSH）；
- `powershell`；
- `playwright`（`python -m pip install playwright`）；
- 本机 Edge + 已登录的 `autodl_browser_profile`。

B 实例的 Python 如未安装 playwright，只能使用 SSH 类工具，`cloud_power` 会失败。
